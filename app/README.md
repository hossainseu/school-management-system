# School Management System

A Laravel 12 based School Management System with authentication, role-based access control, academic management, attendance, results, and financial management.

## Technology Stack

- Laravel 12
- PHP 8.4+
- MySQL
- Laravel Breeze
- Vite
- Tailwind CSS / Application CSS
- XAMPP
- Laravel Herd
